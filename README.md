# rohitmishra.me

Personal website for Rohit Mishra, built with [Astro](https://astro.build/) and deployed to GitHub Pages.

## Local development

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
pnpm preview
```

## Deployment

The site deploys from `master` through GitHub Actions to GitHub Pages. The canonical domain is `www.rohitmishra.me`, configured via `public/CNAME` and `astro.config.mjs`.

## Content direction

This is intentionally a clean restart. The old Octopress/Jekyll blog archive was not migrated.
